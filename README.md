# 野生狗奶

适用于 Minecraft Java Edition 1.20.1 与 Forge 47.x。

## 下载

请前往 [GitHub Releases](https://github.com/kldsjfas/wild-dog-milk/releases/latest) 下载最新版 JAR，不要下载 GitHub 自动生成的 Source code 压缩包。

这是一个以网络梗为灵感制作的娱乐向食物模组，加入三件效果夸张的中文物品：

- **野生狗奶**：提供持续不死、夜视、100 倍昼夜加速与范围伤害；手持时吸引狼，按住 Shift 右键可喂给自己驯服的狼。
- **春秋肠**：随机将玩家回溯到 10～60 秒前；若身上已有狗奶不死效果，则会直接终结该效果并杀死玩家。
- **菊花饮料**：让玩家化作持续 30 秒的移动黑洞，吞噬实体与地形，结束时产生大型爆炸并杀死玩家。

## 安装

1. 安装 Minecraft 1.20.1 与 Forge 47.x。
2. 将 JAR 文件放入该游戏实例的 `mods` 文件夹。
3. 客户端与服务端需要安装相同版本。

## 注意

- 菊花饮料会大范围破坏地形，请先备份存档。
- 本模组不包含联网、遥测、上传、下载或账户读取功能。
- 公开版使用原创合成音频，不包含本地试玩版使用过的第三方音乐片段。
